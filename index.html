Painel Inicial

⚠️ Aviso importante sobre armazenamento de dados
Este sistema funciona 100% localmente no seu navegador. Nem o GitHub nem qualquer servidor externo armazena suas provas, notas ou dados dos alunos. Seus dados ficam salvos apenas neste navegador e computador.
  • Exportar Backup (obrigatório): sempre que terminar de usar, vá em Dados / Backup e clique em 💾 Exportar Backup. Guarde o arquivo .json — é a única forma de restaurar tudo em outro dispositivo.
  • Baixar TXT: em Resultados, clique em 📄 TXT para gerar um relatório legível. Serve para impressão/arquivamento, mas não restaura o sistema.
  • Atenção: limpar os dados do navegador sem backup apaga tudo permanentemente.
